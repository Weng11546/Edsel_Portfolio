IT Help Desk Ticket Analysis

An Excel analysis of 50 IT help desk tickets that looks at response and resolution times, ticket volume, first-contact resolution, technician performance, and customer satisfaction, then recommends improvements.

Project overview

This project analyzes help desk ticket data from five departments (Finance, HR, IT, Library, Registrar). Using Excel formulas, a pivot-style summary, and charts, it measures how quickly tickets are answered and resolved and how satisfied users are.

Problem statement

Help desk managers need to know which issues are most common, whether urgent tickets are handled fast enough, and how evenly work is shared among technicians, so they can improve service quality.

Objectives

  • Check the dataset for missing values, invalid entries, and duplicates.
  • Summarize response time, resolution time, and satisfaction.
  • Compare ticket volume and performance by issue type, priority, and technician.
  • Identify patterns and give recommendations.

Target users

  • Help desk managers
  • IT support supervisors
  • School or office administrators

Dataset

The Raw_Data sheet holds 50 tickets (TK4000–TK4049) logged over 50 days, with these variables: Ticket_ID, Day, Department, Issue_Type, Priority, Response_Minutes, Resolution_Hours, Resolved_First_Contact, Technician, and Satisfaction (1–5 scale).

The workbook also includes a Data_Dictionary, the Tasks list, the answers in Tasks(Answer), an Analysis sheet, a PivotTable sheet, and a Charts sheet.

Key patterns

  • Critical tickets wait longer for a response (62.3 min) than High (32.4 min) and even Low (57.0 min) tickets.
  • Password issues are the most common (24% of tickets) and take the longest to resolve (7.7 hrs).
  • Only 58% of tickets are resolved on first contact, so 42% need follow-up.
  • Workload is uneven: Ben handles 17 tickets versus Ana's 7, and the two busiest technicians (Ben and Dina) have the lowest satisfaction.

Recommendations

  • Fix triage so Critical tickets are routed and answered fastest.
  • Add a self-service password reset tool or better documentation.
  • Rebalance assignments and train for first-contact resolution.

Limitations

  • Only 50 tickets, so results may not generalize.
  • The PivotTable sheet uses COUNTIFS/AVERAGEIFS rather than a native Excel PivotTable.

Future improvements

  • Analyze a larger, multi-month dataset to check for trends over time.
  • Build an interactive dashboard (for example in Power BI).
